VAO Academy v5 – Integrated Prototype

This is the next build, not a disconnected replacement.

It integrates the main functions from the earlier versions into one prototype:
- School Profile
- Dashboard
- Teachers
- Students
- Classes
- Subjects
- Teacher -> Subject -> Class assignments
- Teacher login
- Teacher dashboard
- Teacher-specific classes/subjects/students
- Assessment entry
- Formative /40
- Summative /60
- Final /100
- Grade and PASS/FAIL
- All Assessments
- School Results
- Report Cards
- Compare Results
- Backup / Restore
- VAO Academy logo
